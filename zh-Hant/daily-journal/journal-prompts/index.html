每天都能用的日記題目

最後更新：2026年8月

有沒有題目，決定了你是盯著空白頁面四分鐘，還是四分鐘內寫完一篇。在那些「什麼事都沒發生」的日子裡，題目往往是這一篇之所以被寫下來的唯一理由。

挑一則，誠實地回答，寫完就停。第一次嘗試嗎？如何開始寫日記會告訴你一篇正常的日記長什麼樣子。

怎麼使用題目（以及什麼時候該無視它）

三條規則。回答你被問到的那個問題，而不是那個聽起來比較體面的版本。念頭想完就停——兩句話就是一篇完整的日記。當更好的東西冒出來時就丟掉題目；它唯一的任務就是讓你動起來。依你的狀態來挑：

如果你覺得……就去看為什麼
匆忙，一天剛開始早晨題目簡短、朝前看，兩分鐘
疲憊，一天結束夜晚題目為這一天收尾，不再打開新的循環
腦袋空白，什麼都沒發生卡住時的題目不需要今天提供任何素材
心煩、焦慮、緊繃難熬日子的題目把在腦中打轉的東西倒出來
平淡但還好感恩題目小、具體，效果安靜而扎實
站在人生的岔路上規劃題目把模糊的決定變成寫下來的決定

早晨與夜晚的題目

早晨（2–3 分鐘）

簡短、朝前看；還沒喝咖啡就要分析，一定會輸。

  1. 有哪一件事，做到了就會讓今天覺得值得？
  2. 我在害怕什麼事，而它實際上要花多久？
  3. 我昨晚睡得如何？這對今天的安排代表什麼？
  4. 今天有誰會因為收到我的訊息而好過一些？
  5. 我關掉這一頁之後，第一件要做的事是什麼？
  6. 如果今天很不順，最小的版本要做到什麼程度才算完成？

夜晚（3–5 分鐘）

把這一天放下，不要再重新打開它。

  1. 今天到底發生了什麼？三句話，不做分析。
  2. 有什麼比我預期的順利？
  3. 今天還有什麼留在我身上？它需要跟我一起上床嗎？
  4. 有什麼現在可以不用再想了，因為明天的我會處理得更好？

每日日記範本可以把這些變成每晚的固定欄位；晨間手記則把早晨這件事推得更遠。

當你卡住時，以及當這一天很難熬時

卡住的日子

這些題目不需要今天提供任何素材——空白的一天正好需要這樣。

  1. 這幾年來，有什麼事是我改變了看法的？
  2. 有什麼是我一直想做、卻一直沒做的？真正擋在中間的是什麼？
  3. 十五歲時我以為的成年人生活，哪些後來證明是錯的？
  4. 有誰在無意間教會了我某件事？
  5. 有什麼小事，總是能讓我的一天變好一點？
  6. 如果現實條件都不重要，我會怎麼度過一個完全自由的星期六？

難熬的日子

朝著那件事寫，不要繞著它寫——寫「失望，而且有點難為情」，會發生一些寫「很糟」不會發生的事。

  1. 到底發生了什麼？照順序平鋪直敘，不加任何詮釋。
  2. 我現在有什麼感覺？盡我所能把它精確地命名出來。
  3. 我害怕這件事代表我是什麼樣的人？那是事實，還是恐懼？
  4. 這件事哪一部分該由我來處理，哪一部分不是？
  5. 如果是朋友向我描述一模一樣的處境，我會對他說什麼？
  6. 實際上最壞的結果是什麼？我承受得住嗎？
  7. 我現在需要的是什麼——睡眠、食物、一場對話、一句道歉，還是去散個步？

如果同一個擔憂一直回來，寫日記面對焦慮與壓力談了什麼有幫助，以及書寫做不到的事。

回顧與感恩的題目

回頭看

最適合每週或每月一次——這些題目是在閱讀你的人生，而不只是記錄它。

  1. 跟一年前的我相比，有什麼不一樣了？
  2. 這個月我把最多時間花在什麼上面？那是我原本的計畫嗎？
  3. 今年做的哪一個決定，我最慶幸自己做了？
  4. 我還在哪些地方，依照別人訂下的規則過日子？
  5. 這個月的日記裡，有什麼一再出現？
  6. 有什麼是我引以為傲、但沒有人會想到要恭喜我的？

感恩

具體勝過宏大：「我的家人」什麼都生不出來；「我女兒在電話裡道別的方式」則能生出一整篇。

  1. 今天有什麼事很順利，是我平常根本不會注意到的？
  2. 這週有誰讓我的事情變得比較輕鬆？
  3. 我現在擁有的東西裡，有哪一樣是我曾經非常渴望的？
  4. 如果我日常作息中的某一部分消失了，我最會想念哪一部分？
  5. 最近有什麼讓我笑了出來？

如果你被這一類吸引，如何寫感恩日記談了怎麼讓它保持新鮮。

規劃與做決定的題目

把一個決定寫下來，會讓模糊的偏好變成明確說出口的偏好——而有一半的時候，你其實早就知道答案了。

  1. 我真正在決定的是什麼？用一句話說清楚。
  2. 如果不管我怎麼選、都沒有人會知道，我會選哪一個？
  3. 這個決定有沒有可逆的版本——有沒有辦法先小規模試試看？
  4. 有什麼是我早就知道、卻假裝不知道的？
  5. 下一個具體的行動是什麼？我到底會在什麼時候做？
  6. 誰已經做過這件事了？我可不可以直接去問他？

最後一題很狡猾：大多數卡住的決定，缺的是一場對話，而不是更多分析。

把題目放在你真的會用到的地方

晚上十點時，一個網頁就是「多了一個分頁」那麼遠——把打動你的題目複製到你真正書寫的地方。在紙本上，把一張寫著題目的小卡貼在筆記本內頁就夠了。在手機上，Feeltracker 每日日記連複製這一步都省了：把喜歡的題目存成可重複使用的範本，這樣每一篇打開時題目就在裡面；搜尋你以前對同一個題目的回答；在你指定的時間收到提醒——預設就是私密的，透過 iCloud 同步、不需要帳號，隨時可匯出成 PDF、XLSX、CSV 或 JSON。

常見問題

一次應該用幾則日記題目？

一則。題目是推你動起來的那一下，不是問卷——一次回答六題，會把書寫變成行政作業。挑那個讓你稍微縮一下的題目；那個縮一下，通常代表底下真的有東西。

日記題目只適合新手嗎？

不是。寫日記的老手最常在最無話可說的日子用它——而那正是習慣最危險的時候。題目也能打破慣性：如果每一篇聽起來都一樣，換一個類別的問題是最快的解方。

焦慮時適合用什麼日記題目？

具體的那些。「到底發生了什麼，不加任何詮釋」和「這件事哪一部分該由我來處理」，比開放式的感受型問題更有用，後者容易滑向反芻思考。完整的做法與它的限制，見寫日記面對焦慮與壓力。

同一個題目可以回答不只一次嗎？

可以——而且要刻意這麼做。每個月重複同一個題目，會把它變成一種量測：同一個問題在三月和九月的答案，會顯示出你日常根本察覺不到的變化。能夠搜尋你以前的答案，讓這件事變得實際可行。

如果一個題目寫不出什麼名堂怎麼辦？

寫兩句話之後就丟掉它，換一個。一個沒有接住你的題目不是失敗的日記，只是問錯了問題——你不過損失了三十秒。唯一糟糕的結果，是因為第一個問題不管用就把日記闔上。

關於身心健康的小提醒

寫日記是一種身心保健的練習，不是治療。題目可以讓困難的感受比較容易靠近，但無法取代專業的心理健康支持。如果書寫持續浮現出令你痛苦的內容——長期的低落情緒、無法緩解的焦慮，或是傷害自己的念頭——請找醫生或心理師談談。若你正處於危機中，請聯絡當地的緊急電話或你所在國家的心理危機專線（在台灣：1925 安心專線，24 小時免費）。
