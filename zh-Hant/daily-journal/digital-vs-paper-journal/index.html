數位日記與紙本日記

最後更新：2026年8月

大多數關於數位與紙本日記的比較，都是由賣其中一種的人寫的——包括這一篇。先從兩邊都成立的事實開始：你真的會去寫的那一本，就是最好的那一本，而真正重要的差別會出現在第二年，不是第一週。

紙本勝在那些難以複製的東西——儀式感、沒有通知，以及手寫那份有用的緩慢。數位勝在那些不起眼的基礎設施：搜尋、備份、放在口袋裡，以及二十年後依然讀得到。以下是完整的比較，以及對雙方都公平的論述。如果你還沒開始，別讓這個選擇拖住你——如何開始寫日記兩邊都適用。

紙本勝出的地方跟書寫的體驗有關；數位勝出的，則是書寫之後發生的一切。

紙本真正勝出的地方

這些是真正的優勢，不是安慰獎。手寫會改變你思考的方式：關於課堂筆記的研究一致發現，較慢的媒介會逼你摘要，而摘要就是思考——這正是晨間手記要求手寫的原因。一本筆記本裡除了你的日記什麼都沒有。儀式感確實有效：特定的一本子和一枝筆，會成為這個練習的觸發線索——很多在三個應用程式上都失敗的人，在筆記本裡寫得很勤。不依賴任何人：筆記本不會被停止服務、不會被併購，也不會突然改成訂閱制——五十年後它依然打得開。而且它會變成一件物品：一整層架子的寫滿筆記本，有著任何資料夾都不會有的重量；如果這本日記是打算傳給後人的，紙本更好。

數位真正勝出的地方

都是些乏味的面向——正因如此，它們才會在數年之後決定勝負。搜尋是顛覆性的：在筆記本裡，那篇關於你祖母的紀錄實際上是找不到的；打成文字之後，一個名字或一個恐懼，一秒鐘就能召回五年間的每一次提及。長期價值大多在重讀裡——而紙本悄悄地讓重讀不會發生。它在你身邊：值得被接住的念頭出現在公車上或凌晨兩點；一本只待在家裡的日記，是靠記憶事後補寫的——而記憶會自行整理。遺失不是終局：筆記本會被忘在火車上；有同步的日記，就算手機毀了也還在。其餘的還有：點兩下加照片、語音輸入、深色模式，以及那些橫跨數月、沒有人會用手翻出來的主題整理。

但書是：這一切都取決於你能不能把自己的文字拿出來——先確認有沒有 PDF、CSV、XLSX 或 JSON 匯出。

隱私：大家常常搞反的那個面向

直覺會說紙本比較私密：沒有公司介入。這只對了一半。筆記本沒有任何存取控制：家裡任何人都可以讀到每一個字，而你永遠不會知道。對於任何在書寫一段關係、健康狀況或工作的人來說，這才是真正的風險。手機預設就是鎖著的：Face ID 對那種隨手翻閱的讀者是個實實在在的障礙——而那正是筆記本毫無防禦能力的對象。你換來的問題則是：它需要帳號嗎（用你自己的 iCloud，就不會留下任何綁定你身分的副本）？你的篇章存放在哪裡？你能不能把全部匯出？如果它免費，是不是你在用別的方式付費？

公允的結論是：紙本對「公司」比較私密，數位則對「跟你同住的人」比較私密。對大多數人來說，後者更重要。

大多數人最後會走到的混合做法

你不必選邊站；許多長期寫日記的人也沒有。用紙本做那種「想到哪寫到哪」的書寫——晨間手記、一個難熬的夜晚——這種時候書寫這個動作本身就是重點。用數位做紀錄——每日的流水帳、照片，以及任何你會很不想弄丟、或需要在外面寫的東西。子彈筆記兩邊都能跑，而它那些手工苦差事，正是數位版本會拿掉的部分。決定性的因素是持續性：養成寫日記的習慣比你把它建立在什麼載體上更重要。

常見問題

寫日記時手寫比打字好嗎？

就*思考*而言，往往是的——關於手寫筆記的研究一致發現，較慢的媒介會改變你處理所寫內容的方式，這正是晨間手記這類練習指定手寫的原因。但就*保存紀錄*而言，打字輕鬆勝出：可搜尋、有備份，而且不管你在哪裡都用得到。很多人兩種都做，用在不同類型的書寫上。

筆記本和日記應用程式，哪個比較私密？

取決於你要防的是誰。筆記本沒有任何存取控制——家裡任何人都讀得到，而你永遠不會知道。手機預設是鎖著的，但應用程式本身很關鍵：優先選擇不需要帳號、並把內容存在你自己的 iCloud 而不是某家公司伺服器上的那一種，並且確認你可以把全部匯出。

如果那個應用程式消失了，我的數位日記會怎麼樣？

在投入好幾年的書寫之前，這正是該問的問題。答案是匯出：如果一款應用程式能給你全部內容的 PDF、CSV、XLSX 或 JSON 副本，那它被放棄只會花掉你一個下午，而不是你的整個檔案庫。一款沒有匯出功能的應用程式，確實比筆記本更冒險。

可以同時使用紙本和數位日記嗎？

可以，而且這是很常見的配置。紙本用來做那種開放式、想到哪寫到哪、而且你永遠不會重讀的書寫；數位用來做紀錄——有日期的篇章、照片，以及任何你會很不想弄丟、或日後想找出來的東西。沒有規定不能有兩本日記，也沒有人在給你打分數。

數位日記比較便宜嗎？

通常會便宜一點點。一本像樣的筆記本大約 150 到 900 元，而你一年會寫完好幾本；日記應用程式則從免費到每月幾十元不等，有些完全免費。實際上成本幾乎打平——這不該是替你做決定的那個因素。
