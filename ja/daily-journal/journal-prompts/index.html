毎日のための日記のお題

最終更新：2026年8月

お題があるかどうかで、白紙のページを4分眺めるか、4分で1日分を書き終えるかが変わります。何も起きなかった日には、お題があることだけが、その日の記入が書かれる唯一の理由になることもよくあります。

1つ選んで、正直に答えて、答え終わったらやめる。それだけです。日記そのものが初めてなら、日記の始め方で「普通の1日分」がどんなものかを確認できます。

お題の使い方（と、無視していいとき）

ルールは3つ。聞かれた質問に答えること — かっこよく見えるほうの答えではなく。考えを言い終えたらやめること — 2文で立派な1日分です。もっといいことが出てきたらお題は捨てること。お題の仕事は、あなたを動かし始めることだけです。今の状態から選びましょう。

こんな気分なら…これを見る理由
慌ただしい、1日の始まり朝のお題短く、前向きで、2分で終わる
疲れている、1日の終わり夜のお題その日を閉じる。新しい宿題を作らない
頭が真っ白、何も起きなかった書くことがない日のお題今日の出来事を必要としない
ぐるぐる考える、不安、緊張しているつらい日のお題頭の中の堂々めぐりを外に出す
平坦だけど問題はない感謝のお題小さく、具体的で、静かに効く
岐路に立っている計画のお題ぼんやりした決断を、言葉にされた決断に変える

朝と夜のお題

朝（2〜3分）

短く、前を向いて。コーヒーの前の分析は、たいてい負けます。

  1. 今日を「やった甲斐があった」と思わせてくれる、たった1つのことは？
  2. 気が重いのは何？ 実際にはどのくらい時間がかかる？
  3. 昨夜はよく眠れた？ それは今日の予定の立て方にどう影響する？
  4. 今日、私からの一言があったら助かる人は誰？
  5. これを閉じたら最初にやることは？
  6. 今日がうまくいかなかったとして、それでも「やった」と言える最小バージョンは？

夜（3〜5分）

その日を下ろす。開き直さない。

  1. 今日、実際には何があった？ 3文で、分析なしで。
  2. 思っていたよりうまくいったことは？
  3. 今日から何をまだ引きずっている？ それはベッドまで連れていく必要がある？
  4. 今はもう考えるのをやめていいことは？ 明日の自分のほうが、それをうまく扱えるから。

日記テンプレートを使えば、これらを毎晩の記入項目にできます。朝についてもっと踏み込みたいならモーニングページがあります。

手が止まったとき、そしてつらい1日だったとき

書くことがない日

今日の出来事をまったく必要としません。空っぽの日に必要なのは、まさにこれです。

  1. ここ数年で、考えが変わったことは何？
  2. ずっとやろうと思っていて、やっていないことは？ 実際、何が邪魔している？
  3. 15歳のとき、大人の生活について信じていたことで、間違っていたことは？
  4. 本人にそのつもりがないまま、私に何かを教えてくれた人は誰？
  5. やると必ず1日がよくなる、小さなことは？
  6. まる1日自由な土曜があったら何をする？ 現実的なことは一切考えずに。

つらい日

そのことの周りを回るのではなく、そのことに向かって書きましょう。「がっかりして、少し恥ずかしかった」は、「最悪だった」にはできない働きをします。

  1. 実際に何が起きた？ 起きた順に、解釈を入れずに。
  2. 今、何を感じている？ できるかぎり正確に名前をつけると？
  3. これが自分について何を意味していると思って怖い？ それは事実？ それとも恐れ？
  4. このうち、自分が引き受けて直すべき部分はどこ？ そうでない部分はどこ？
  5. 友人がまったく同じ状況を話してきたら、私は何と言う？
  6. 現実的にありうる最悪の結果は？ 私はそれに対処できる？
  7. 今、私に必要なのは何？ 睡眠、食事、誰かとの会話、謝罪、散歩？

同じ心配が何度も戻ってくるなら、不安とストレスのための日記で、何が助けになり、書くことでは何ができないのかを扱っています。

振り返りと感謝のお題

振り返る

週に1回、月に1回がおすすめです。これらは生活を記録するのではなく、生活を読むためのお題です。

  1. 1年前の自分と比べて、何が違う？
  2. 今月、いちばん時間を使ったのは何？ それは予定通りだった？
  3. 今年した決断のうち、いちばん「してよかった」と思うのは？
  4. 誰か他の人が決めたルールで、いまだに生きているところはどこ？
  5. 今月の記入に、繰り返し出てきたことは何？
  6. 誰も祝おうとは思わないだろうけれど、自分では誇らしいことは？

感謝

大きなことより具体的なことを。「家族」からは何も出てきませんが、「電話を切るときの娘の言い方」からは1日分が書けます。

  1. 今日うまくいったことで、普段なら気づかずに通り過ぎることは？
  2. 今週、私のために何かを楽にしてくれた人は誰？
  3. 今持っているもので、かつて心から欲しかったものは？
  4. いつもの日課のうち、なくなったらいちばん寂しいのはどの部分？
  5. 最近、笑ったのはどんなこと？

これが気に入ったなら、感謝日記のつけ方で、飽きずに続ける方法を紹介しています。

計画と決断のお題

決断を書き出すと、ぼんやりした好みが、はっきり言葉にされたものに変わります。半分くらいの場合、答えはもう自分で分かっています。

  1. 私は実際、何を決めようとしている？ 1文で言うと？
  2. 誰にも知られないとしたら、どちらを選ぶ？
  3. この決断の「あとから戻せるバージョン」は？ 小さく試す方法はある？
  4. 本当は知っているのに、知らないふりをしていることは？
  5. 次にとる物理的な行動は何で、それをいつやる？ 具体的に。
  6. これをすでにやったことがある人は誰？ その人に聞けば済む話では？

最後のお題は油断なりません。行き詰まった決断の多くは、分析が足りないのではなく、会話が1回足りないだけです。

お題を、実際に使う場所に置いておく

夜10時のあなたにとって、ウェブページは1タブ分だけ遠すぎます。ぴんときたお題は、実際に書いている場所へ写しておきましょう。紙なら、ノートの内側にカードを貼るだけで十分です。スマホなら、Feeltracker日記が写す手間を省いてくれます。お気に入りをくり返し使えるテンプレートとして保存すれば、毎回その質問が入った状態でページが開きます。同じお題への過去の答えを検索でき、あなたの決めた時間にリマインダーが届きます。初期状態でプライベート、アカウント不要のiCloud同期、いつでもPDF、XLSX、CSV、JSONに書き出せます。

明日、何も言うことがない日にも、白紙のページではなく、質問が待っています。

あなたのお題が、アプリの中で待っている

Feeltracker日記なら、好きなお題のセットをくり返し使えるテンプレートとして保存でき、あなたの決めた時間にリマインドし、これまで書いたすべてを検索できます。無料、プライベート、アカウント不要。

よくある質問

1回に日記のお題はいくつ使えばいいですか？

1つです。お題は書き出すための最初のひと押しであって、アンケートではありません。1回で6つに答えると、書くことが事務作業になってしまいます。少しひるむお題を選びましょう。そのひるみは、たいてい何かがそこにあるサインです。

日記のお題は初心者向けのものですか？

いいえ。書き慣れている人ほど、書くことがいちばん少ない日にお題を使います — 習慣がいちばん危うい、まさにその日です。マンネリを壊すのにも役立ちます。どの記入も同じような文章になってきたら、違うカテゴリーの質問を1つ選ぶのがいちばん早い解決法です。

不安なときに向いている日記のお題は？

具体的なものです。「解釈を入れず、実際に何が起きたか」「このうち自分が引き受けて直すべき部分はどこか」は、漠然と気持ちを問う質問よりも効果があります。後者は反すう（同じ考えの堂々めぐり）に傾きやすいためです。全体的な進め方とその限界については、不安とストレスのための日記をご覧ください。

同じお題に何度も答えてもいいですか？

はい — むしろ意識的にどうぞ。同じお題を月に1回くり返すと、それは測定になります。3月と9月の同じ質問への答えを並べると、日々では決して気づけない変化が見えてきます。過去の答えを検索できることが、これを現実的にしてくれます。

お題を選んでも、どこにもたどり着かないときは？

2文で切り上げて、別のお題に移りましょう。引っかからなかったお題は、失敗した記入ではなく、単に合わなかった質問です。失ったのは30秒だけ。唯一まずい結果は、最初の質問がうまくいかなかったからといって日記を閉じてしまうことです。

あわせて読みたい

日記の始め方

「普通の1日分」がどんなものか、そして最初の1週間の進め方。

感謝日記のつけ方

2週間で飽きないように、感謝を具体的に書く方法。

モーニングページ

朝いちばんに3ページ、手直しなし — この実践の由来と、試し方。

心の健康についてのご案内

日記は心の健康を支える実践であり、治療ではありません。お題は、扱いづらい気持ちに近づきやすくしてくれますが、専門的なメンタルヘルスの支援の代わりにはなりません。書くことで苦しさが繰り返し表に出てくる場合 — 気分の落ち込みが続く、不安が和らがない、自分を傷つけたいという考えが浮かぶ — 医師やセラピストに相談してください。危機的な状況にある場合は、お住まいの地域の緊急通報番号か、その国の相談窓口に連絡してください。
