日記の始め方

最終更新：2026年8月

日記を始めること自体は簡単です。多くの人がつまずくのは2回目、3回目の記入のとき — 書くことが難しいからではなく、「普通の1日分」がどんなものかを決めないまま始めるので、毎回同じ問いが戻ってくるからです。結局、何を書けばいいの？

このガイドはその問いに答えます。3分で終わる「十分」の定義、迷う余地をなくした最初の1週間、そして2週目に日記が途絶える、地味だけれど直せる原因をまとめました。

まず、日記の目的を決める

「日記」と一口に言っても、実は5つの異なる習慣が含まれています。最初の1行を書く前に、どれか1つを選びましょう。あとから変えてもかまいませんが、今日の記入には役割が必要です。

  • 考えを整理するため。 頭の中をぐるぐる回っている考えに決着をつけるために書きます。散らかっていても、自分と言い争っていても、それが正解です。
  • 覚えておくため。 何があったか、誰がいたか、どう感じたか。短く、事実中心に。5年後に驚くほど価値が出てきます。
  • 気持ちを吐き出すため。 まだ声に出しては言えないことを紙に置く — 研究の裏づけが最も強いのがこの使い方です（日記の効果をご覧ください）。
  • パターンに気づくため。 睡眠、気分、3週間おきに繰り返される同じ口論。パターンを見つけるには、日付がついて検索できる記録が必要です。
  • 何かを生み出すため。 断片、一節、途中までのアイデア。モーニングページはここに当てはまります。

初心者はこの5つを、しかもきれいな字で、一度にやろうとしがちです。白紙のページが重く感じられるのはそのためです。1回の記入に、目的は1つ。

どのくらい書けば「十分」か

思っているよりずっと少なくて大丈夫です。完成した記入とは3文のこと。起きたこと1つ、それについて感じたこと1つ、覚えておきたいこと、または次にすること1つ。これで丸ごと1日分として成立します。

「プレゼンは無事終わった。思っていたよりよかった。それでも1時間くらい動悸が残っていて、うまくいったのにそれが続くのが腹立たしい。メモ：この動悸は、出来がどうだったかの情報ではない。」

90秒です。何もなかった日は1行 — 「特に何もなし。疲れた。早めに就寝。」— でも立派な記入です。退屈な記入が続くことは、あなたの生活についてのデータであって、書くことの失敗ではありません。項目を埋めていく方が好みなら、日記テンプレートから始めましょう。

初日から守りたいルールが2つ。書きながら読み返さないこと — 途中で手直しを始めると、日記が宿題に変わります。そして最初の2週間はわざと下手に書くこと。誰も読んでいません。想像上の読者がいると、日記は発表会になってしまいます。

最初の1週間は、こちらで決めておきました

日記が続くかどうかを最もよく予測するのは、自分で何かを決めなければならなかったかどうかです。だから、決めなくていいようにしました。各日にお題があり、どれも5分以内で終わります。

日書くこと時間
1そもそもなぜ日記を始めようと思ったか。1か月後、何が変わっていてほしいか。5分
2昨日のことを3文で。起きたことだけ、分析はなし。3分
3ずっと向き合わなきゃと思いながら、手をつけていないこと。5分
4今週うまくいったこと3つ。どんなに小さくても。3分
5心に残っている会話。本当は何と言いたかったか。5分
6まる1日自由になったら何をするか。現実的な制約は考えずに。5分
71週間分を読み返す。1段落で：何が意外だったか？5分

いちばん大事なのは7日目です。自分の1週間を読み返すとき、日記は初めてあなたに何かを返し始めます。そのあとはお題のストックを持っておくと、何もなかった日が「書かなかった日」にならずにすみます。

なぜ2週目でやめてしまうのか

1週目は目新しさで走れます。2週目にはそれがありません。やめる理由は、驚くほど共通しています。

  1. 記入が長くなった。 20分かかる日記は、いつだって睡眠に負けます。習慣を縮める前に、1回分を縮めましょう。
  2. 1日抜けて、連続記録が途切れた。 退屈よりも多くの日記が、これで終わります。1日抜けたことは判決ではありません。次の日の分を書けばいい。遡って埋めない、謝らない。
  3. 時間帯が合っていない。 夜11時に日記が嫌になるなら、悪いのは時間帯であって、あなたではありません。コーヒーの直後、電車の中、停めた車の中などを試してみましょう。
  4. 何も起きなかった。 平坦な日は書けないように感じて飛ばされ、その「飛ばす」が習慣になります。空っぽの日は、代わりに問いに答えましょう。
  5. 誰かのために書いている気がした。 ていねいな字、きれいにまとまった結論。わざと1回、ぐちゃぐちゃに書いて、その声を壊しましょう。
  6. きっかけがない。 「やろう」という気持ちは、きっかけにはなりません。きっかけの作り方と2分バージョンについては日記を習慣にする方法をご覧ください。

このリストにないもの：文章が下手なこと。それを理由にやめる人はいません。

ノートかアプリか：正直な比較

紙のノートは、本当によい日記です。気が散るものがなく、手書きは速度が落ちる分、考えるのを助けてくれます。ベッドの脇にノートを置くやり方が合っているなら、それを使ってください。

紙のコストは、あとからやってきます。検索できない、思いついた瞬間に手元にない、そして明日また書く可能性を高めてくれるものが何もない。Feeltracker日記が埋めるのは、そのわずかな隙間です。

  • いつも手元にある — iPhone、iPad、Macで2タップ。書けなかった日の多くは、やる気ではなく段取りの問題です。
  • 書いたものすべてを横断検索でき、カレンダーからもたどれます。「去年の10月、何があったっけ？」に答えが出せるようになります。
  • くり返し使えるテンプレートでページが白紙になることがなく、リマインダーがあなたの時間帯に届きます。きっかけの問題が、設定1つで解決します。
  • どの記入にもリッチテキストと写真を使えます。
  • 初期状態でプライベート： アカウントもメールアドレスも不要でiCloud同期。いつでもPDF、XLSX、CSV、JSONに書き出せます。
  • 自分の書いたものに対するAIインサイト。無料プランでも使えます。

どちらを選ぶにしても、早く決めて、今夜から始めましょう。気楽に続けられる日記は、2週目で放り出す美しい日記に勝ちます。

ページが白紙にならない

Feeltracker日記は、テンプレートですべての記入が半分書けた状態から始まり、あなたの決めた時間にリマインドし、これまで書いたすべてを検索できます。無料、プライベート、アカウント不要。

よくある質問

最初の日記には何を書けばいいですか？

そもそもなぜ日記を始めようと思ったのか、そして1か月後に何が変わっていてほしいかを書きましょう。あとから「書いておいてよかった」と思える唯一の記入で、頭の中にあること以外に材料は要りません。それでも重すぎるなら、昨日について3文書くだけでかまいません。

1回の日記はどのくらいの長さがいいですか？

3文で完成した記入です。目安は3〜5分 — 一つの考えを言い終えられるだけの長さで、疲れた夜にも負けない短さです。新しく始めた日記が崩れる最大の原因は長さです。迷ったら、少なく書いて、続けましょう。

毎日書かないといけませんか？

いいえ。毎日というのは覚えやすいリズムというだけで、条件ではありません。正直な記入が週に3〜4回のほうが、義務でこなす7回より価値があります。大事なのは、1日抜けたことで習慣が終わらないことです。空いてしまったあとどうするかは、日記を習慣にする方法をご覧ください。

今日は何もなかった日は、どうすればいいですか？

それをそのまま書きましょう。「特に何もなし、疲れた、早めに就寝」は立派な記入ですし、それが続けば、その月について何かを教えてくれます。平坦な日は、代わりに問いに答えるのも手です。まさにこういう日のために、日記のお題をいくつか手元に置いておきましょう。

手書きとスマホ、どちらがいいですか？

実際に続けられるほうです。手書きは遅い分、考えるのを助けてくれることがあります。スマホは思いついた瞬間に手元にあり、何年後でも検索できます。以前に紙の日記を挫折したことがあるなら、原因はおそらく段取りの部分 — まさにアプリが解決してくれるところです。

心の健康についてのご案内

日記は心の健康を支える実践であり、治療ではありません。振り返りを助けてくれますが、専門的なメンタルヘルスケアの代わりにはなりません。書くことで苦しさが繰り返し表に出てくる場合 — 気分の落ち込みが続く、不安が和らがない、自分を傷つけたいという考えが浮かぶ — 医師やセラピストに相談してください。危機的な状況にある場合は、お住まいの地域の緊急通報番号か、その国の相談窓口に連絡してください。
