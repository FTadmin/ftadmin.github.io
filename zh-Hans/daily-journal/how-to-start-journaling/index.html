如何开始写日记

最近更新：2026年8月

开始写日记很容易，真正卡住人的是第二篇和第三篇——不是因为写作有多难，而是因为你从没决定过“一篇普通的日记该是什么样”，于是每次坐下来都要重新面对同一个问题：我到底该写什么？

这份指南就是来终结这个问题的：一个三分钟就能达到的“写够了”的标准、一份已经替你做好所有决定的第一周计划，以及那些让日记死在第二周的、平淡却完全可以解决的原因。

第一步：想清楚你的日记是用来做什么的

“写日记”其实涵盖了五种完全不同的习惯。在写第一篇之前先选一种——以后随时可以改，但今天这一篇需要有个明确的任务。

  • 为了把事情想清楚。你写，是为了把一直在脑子里打转的念头想完。写得凌乱、自相辩论，才是对的。
  • 为了记住。发生了什么、谁在场、当时是什么感觉。简短、写实，五年后回看会意外地珍贵。
  • 为了释放压力。把那些还说不出口的东西放下来——这也是研究证据最充分的一种用法（参见写日记的好处）。
  • 为了发现规律。睡眠、心情、每隔三个星期天都会吵的那一架。要看出规律，就需要有日期、可搜索的记录。
  • 为了创作。片段、句子、半成形的想法。晨间笔记就属于这一类。

新手往往在不知不觉中想同时做到这五件事，还想写一手漂亮的字——这正是空白页让人喘不过气的原因。一篇日记，一个目的。

写多少才算够

比你以为的少得多。一篇完整的日记只需要三句话：发生了一件什么事、你对它有什么感受、有什么要记住或接下来要做的事。这就是一篇完整的日记，完全算数：

“汇报还挺顺利的，比我预想的好。可结束后我还是抖了一个小时，明明进行得很顺利，这点挺烦人的。备注：那种发抖并不能说明汇报到底怎么样。”

九十秒搞定。平淡的日子里，写一行——“没什么事。累。早睡。”——也依然是一篇真正的日记；一连串乏味的记录是关于你生活的数据，而不是写作上的失败。更想按栏目填空？那就从一份每日日记模板开始。

从第一天起就守住两条规则：写的时候绝不回头重读——写到一半就开始修改，会把写日记变成写作业；以及在最初两周里故意写得糟糕一点。没有人会看这些内容；一个想象中的读者会把日记变成一场表演。

第一周，已经替你安排好了

写日记能不能坚持下来，最好的预测指标是：你是否还需要自己做决定。所以，别做——每天都有既定的题目，没有一天需要超过五分钟。

第几天写点什么时长
1你究竟为什么想开始写日记。你希望一个月后有什么不一样。5分钟
2用三句话写昨天。只写发生了什么，不做分析。3分钟
3那件你一直想处理、却始终没动的事。5分钟
4这一周里顺利的三件事，再小也算。3分钟
5一段一直留在你心里的对话。你其实真正想说的是什么。5分钟
6如果有完全自由的一天，你会怎么过。不考虑任何现实限制。5分钟
7重读这一周。写一段话：什么让你意外？5分钟

第7天最关键：重读自己的一周，正是写日记开始给你回报的时刻。之后，随身备一叠日记提示，这样平淡的一天就不会变成空白的一天。

为什么人们在第二周放弃

第一周靠新鲜感撑着，第二周就什么也不剩了。人们放弃的理由惊人地一致：

  1. 写得太长了。一篇要花二十分钟的日记，永远赢不了睡意。先缩短篇幅，别缩短习惯。
  2. 漏了一天，连续记录断了。因此夭折的日记比因为无聊而夭折的还多。漏一天不是判决书——直接写下一篇，别补记，也别道歉。
  3. 时间点不对。晚上11点讨厌写日记，说明这个时间不对，不是你不对。试试刚喝完咖啡后、通勤路上、或者停好车还没下车的那几分钟。
  4. 什么都没发生。平淡的日子让人觉得无从下笔，于是跳过，而跳过本身成了习惯。空白的一天，就改成回答一个问题。
  5. 感觉像是写给别人看的。工整的字迹、漂亮的结论。用一篇故意写得难看的日记打破这种腔调。
  6. 没有触发点。“打算写”并不是触发信号——关于触发点的设计和两分钟版本，参见如何养成写日记的习惯。

不在这份清单上的是：文笔不好。没有人因为这个而放弃。

纸质本还是应用：一个诚实的比较

纸的代价来得比较晚。你没法搜索它，念头冒出来的时候它往往不在身边，而且它本身并不会让你明天更可能再写一篇。这正是Feeltracker每日日记填补的那道窄缝：

常见问题

第一篇日记该写什么？

写下你究竟为什么要开始写日记，以及你希望一个月后有什么不一样。这是你日后最庆幸自己写过的一篇，而且不需要任何素材，全在你脑子里。觉得题目太大？那就用三句话写写昨天。

一篇日记应该写多长？

三句话就是一篇完整的日记。目标是三到五分钟——足够把一个想法写完，又短到即使在疲惫的夜晚也赢得过睡意。篇幅是新日记夭折最常见的原因；拿不准的时候，就写少一点，然后继续写下去。

必须每天都写吗？

不必。每天写只是最容易记住的节奏，而不是硬性要求——一周写三四篇真诚的，胜过七篇敷衍的。关键在于，漏掉一天不会终结这个习惯。断了之后该怎么办，参见如何养成写日记的习惯。

如果今天什么都没发生怎么办？

那就把这件事写下来。“没什么事，累，早睡”就是一篇真正的日记，而一连串这样的记录也在告诉你这个月过得如何。平淡的日子里，改成回答一个问题——手边常备几条日记提示，正是为了应付这种时候。

该手写还是在手机上写？

哪种你真的会去做就选哪种。手写更慢，而这种慢有时有助于思考；手机则在念头冒出来时就在你身边，而且多年后还能搜索到。如果你以前放弃过纸质日记本，问题多半出在不方便——而这恰恰是应用能解决的部分。
