每天都能用的日记提示

最近更新：2026年8月

有没有一条提示，决定了你是盯着空白页发呆四分钟，还是四分钟内写完一篇。在“今天什么都没发生”的日子里，它往往是这篇日记能被写下来的唯一原因。

挑一条，诚实地回答，写完就停。刚开始写？如何开始写日记讲的是一篇普通日记该是什么样。

怎么用提示（以及什么时候该无视它）

三条规则。回答别人问你的那个问题，而不是那个听起来更漂亮的版本。想法写完就停——两句话就是一篇完整的日记。一旦冒出更值得写的东西，就抛开提示；它唯一的任务就是让你动笔。按你的状态来挑：

如果你觉得……就去看为什么
匆忙，一天刚开始早晨的提示简短、朝前看，两分钟搞定
疲惫，一天快结束夜晚的提示为这一天收尾，不再打开新的心结
脑子空白，什么都没发生写不出来时的提示不需要今天提供任何素材
心里翻腾、焦虑、紧绷难熬时的提示把打转的念头从脑子里搬出来
平淡，但还好感恩的提示小而具体，效果悄无声息
站在岔路口计划与决定的提示把模糊的选择变成写下来的选择

早晨和夜晚的提示

早晨（2–3分钟）

简短、朝前看；还没喝咖啡就做分析，注定是输的。

  1. 今天做成哪一件事，就会让这一天值得？
  2. 我在害怕什么？它实际上要花多久？
  3. 我睡得怎么样？这对我今天该怎么安排意味着什么？
  4. 今天有谁会因为收到我的一条消息而开心？
  5. 关掉这一页之后，我要做的第一件事是什么？
  6. 如果今天很不顺，什么样的最小版本仍然算完成？

夜晚（3–5分钟）

把这一天放下，别再重新打开它。

  1. 今天到底发生了什么？三句话，不做分析。
  2. 什么比我预想的更顺利？
  3. 今天有什么我还背着？它需要跟我一起上床吗？
  4. 什么现在可以不再想了，因为明天的我会处理得更好？

每日日记模板可以把这些变成每晚固定填写的栏目；晨间笔记则把早晨的书写推得更远。

写不出来的时候，和难熬的那一天

写不出来的日子

这些提示完全不需要今天提供素材——正是空白的一天所需要的。

  1. 最近这几年，我改变了看法的一件事是什么？
  2. 有什么我一直想做、却一直没做？真正挡在中间的是什么？
  3. 十五岁时我对成年生活的哪些想法，后来证明是错的？
  4. 谁在无意之中教会了我一些东西？
  5. 哪件小事总能可靠地让我这一天变好？
  6. 如果完全不考虑现实，一个彻底空闲的周六我会怎么过？

难熬的日子

朝着那件事写，而不是绕着它写——“失望，还有点难堪”能起到的作用，是“糟透了”起不到的。

  1. 究竟发生了什么？按顺序平铺直叙，不做任何解读。
  2. 我现在的感受是什么？尽可能精确地把它叫出名字。
  3. 我担心这件事说明我是个什么样的人？那是事实，还是恐惧？
  4. 这件事里哪部分是我该去解决的，哪部分不是？
  5. 如果是朋友向我描述一模一样的处境，我会对他说什么？
  6. 现实中最坏的结果是什么？我扛得住吗？
  7. 我此刻真正需要的是什么——睡觉、吃饭、一次谈话、一句道歉，还是出去走走？

如果同一份担忧反复回来，用写日记应对焦虑与压力讲了哪些做法有用，以及书写做不到什么。

回顾与感恩的提示

回头看

最适合每周或每月用一次——这些提示不是记录你的生活，而是阅读它。

  1. 和一年前相比，我身上有什么不一样了？
  2. 这个月我把最多时间花在了什么上？那是原本的计划吗？
  3. 今年做过的哪个决定，我最庆幸自己做了？
  4. 我在哪些方面，仍然按照别人定下的规则生活？
  5. 这个月我的日记里反复出现的是什么？
  6. 有什么是我引以为豪、却没人会想到要祝贺我的？

感恩

具体胜过宏大：“我的家人”写不出东西；“我女儿在电话里说再见的那个语气”能写出一篇日记。

  1. 今天有什么顺利的事，是我平常根本不会注意到的？
  2. 这一周谁让我的事情变得更容易了？
  3. 我现在拥有的东西里，有哪一样是我曾经真心想要的？
  4. 如果我日常生活中的哪一部分突然消失，我会最想念它？
  5. 最近有什么让我笑了？

如果这一类吸引你，如何坚持写感恩日记讲了怎样让它保持新鲜。

计划与决定的提示

把一个决定写下来，能让模糊的倾向变成明确的表态——有一半的时候，你其实早就知道答案了。

  1. 我到底在决定什么？用一句话说清楚。
  2. 如果没有人会知道我选了哪一边，我会怎么选？
  3. 这个决定有没有可逆的版本——有没有办法先小小地试一次？
  4. 有什么是我其实已经知道、却假装不知道的？
  5. 下一个具体的动作是什么？我到底什么时候去做？
  6. 谁已经做过这件事？我能不能直接去问他？

最后一条最容易被忽略：大多数卡住的决定，缺的是一次谈话，而不是更多分析。

常见问题

一次该用多少条日记提示？

一条。提示是推你起步的那一下，不是问卷——一口气答完六条，写日记就变成了办公事。挑那条让你稍微有点抗拒的；那份抗拒通常说明里面确实有东西。

日记提示只适合新手吗？

不是。写日记多年的人，反而在最无话可说的日子里用得最多——而那正是习惯最容易断掉的时候。提示还能打破套路：如果每篇日记都写得差不多，换一个类别的问题是最快的解法。

应对焦虑，哪些日记提示比较好用？

具体的那些。“究竟发生了什么，不做任何解读”和“这件事里哪部分是我该解决的”，比开放式的感受类问题更有用，后者容易滑向反复咀嚼。完整的做法和它的局限，参见用写日记应对焦虑与压力。

同一条提示可以回答不止一次吗？

可以——而且要有意为之。每月重复同一条提示，它就变成了一把尺子：三月和九月对同一个问题的回答，会显出你日复一日绝不会察觉的变化。能够搜索自己过去的回答，让这件事真正可行。

如果一条提示写不下去怎么办？

写两句就放掉它，换一条。没接住的提示不是失败的一篇日记，只是一个不合适的问题——你不过损失了三十秒。唯一糟糕的结果是：因为第一个问题不管用，就把日记本合上了。

关于身心健康的提醒

写日记是一种促进身心健康的日常练习，而不是治疗手段。提示能让难以面对的情绪更容易被接近，但它们不能替代专业的心理健康支持。如果书写持续引出强烈的痛苦情绪——长期情绪低落、无法缓解的焦虑，或伤害自己的念头——请与医生或心理治疗师谈一谈。如果你正处于危机之中，请拨打当地的急救电话或所在国家的心理危机干预热线。
