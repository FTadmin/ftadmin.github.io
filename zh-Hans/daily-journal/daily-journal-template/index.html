每日日记模板

最近更新：2026年8月

模板是应对空白页最省事的办法。你不需要决定写什么，只需要填空——于是在那些你差点跳过的夜里，一篇九十秒的日记依然会被写下来。

下面是五种版式，可以照搬到笔记本、备忘录或日记应用里。先用一种坚持两周，然后删掉那些没有存在价值的栏目——你自己改过的模板，胜过你照单全收的模板。

什么样的模板才管用

网上大多数模板都很漂亮，有十一个栏目，然后被用了四次。三条规则能让一个模板活下来：

  • 最多四到六个栏目。每个栏目都是每晚要交的一笔税；凡是你连着跳过两次的，删掉。
  • 每个栏目都是一个问题，而不是一个话题。“反思”只会换来发呆；“什么比我预想的更顺利？”能换来一句话。
  • 留一个开放栏目。结构过于完整的日记会变成填表；那些你没打算写的东西，需要一个能落脚的地方。

一次性想清楚这个模板是用来做什么的——记忆存档、压力出口和规划工具，在纸上的样子完全不同。如何开始写日记详细讲了这个选择。

模板1——五分钟日常版

默认之选：在记录和反思之间取得平衡，又短到足以熬过糟糕的夜晚。

栏目写什么时长
日期与心情日期，加上一两个词形容这一天的感觉10秒
发生了什么三句话，只写事实，不做解读1分钟
我对此有什么感受那种感受，尽可能精确地叫出名字1分钟
一件好事一件具体的、顺利的事，再小也算30秒
还在心里的事开放栏目——任何还在打转的东西2分钟

填好之后：

“8月12日 周二——平淡，但还行。交接文档写完了，和Sam通了很久的电话。文档写完松了口气，但没人注意到，有点泄气。一件好事：走回来的那段路。还在心里的事：我其实比自己愿意承认的更希望被看见。”

九十秒，而最后那一行才是最值得留下的。

模板2——晚间回顾

用来为一天收尾；如果你写日记是为了睡得更好，就用这个。

  1. 用一句话概括今天。
  2. 什么比我预想的更顺利？把注意力从这一天最糟的时刻上挪开。
  3. 什么消耗了我？拉长到一个月看，这是这里信息量最大的一栏。
  4. 我还背着什么？所有没完成的事，一股脑倒出来。
  5. 它需要跟我一起上床吗？要么把每一项先搁置，要么写下下一步动作和时间。
  6. 今天有一件让我庆幸的事。要具体——“爸爸被自己的笑话逗笑的样子”，而不是“我的家人”。

第四步和第五步是真正起作用的部件：一个悬着的心结之所以让你睡不着，是因为它没被存放在别处，而写下来的下一步动作，足以把它关得够好、够你入睡。如果你被感恩这一类吸引，如何坚持写感恩日记讲了怎样让它保持新鲜。

模板3——每周复盘

每周一次，固定在同一天，十到十五分钟。这是本页价值最高的模板，而且遥遥领先：每日的记录是在记，而复盘才是你阅读自己生活的时刻。要取舍的话，先放弃其他一切，也别放弃它。

环节提示
重读先把这一周的日记读一遍。先别写任何东西。
规律什么不止出现了一次？我一直在绕着什么打转？
收获三件顺利的事，包括那些没人会想到要祝贺我的。
消耗我的精力实际去了哪里？那是原本的计划吗？
未完成还有什么悬着？说实话，哪些会一直悬着？
下周一件要多做的，一件要少做的，一个带具体日期的承诺。

人们总跳过第一行，而它恰恰是复盘之所以有效的原因：重读一周，会浮现出任何单篇日记都不包含的规律——这正是持久的写日记习惯赖以运转的、看得见的回报。

模板4和5——一行流水账与难熬的一天

一行流水账

适合忙碌的时期和出差的那几周。格式：日期——一句话。

  • 8月12日——回来上班第一天，收件箱还算撑得住，昨晚没睡好。
  • 8月13日——午饭时听到Sam的消息。还在消化。

它看起来微不足道，其实不然：一整年的一行流水账就是一份真实的记录，只花十五秒，而且能带着这个习惯挺过那些本会让它断掉的星期。把它正式定为你的备用方案，而不是“今晚就跳过吧”。

难熬的一天

用于真的出了岔子的日子。

  1. 发生了什么，按顺序平铺直叙，不做任何解读。
  2. 我的感受是什么，尽可能精确地叫出名字。
  3. 我担心这件事意味着什么。然后问：这是事实，还是恐惧？
  4. 哪部分是我该解决的，哪部分不是。列成两份清单。
  5. 如果是朋友处在一模一样的处境里，我会对他说什么。
  6. 我此刻真正需要什么——睡觉、吃饭、一次谈话，还是出去走走。

第一步把“发生了什么”和“你得出的结论”分开——这两样通常是纠缠在一起的。如果同一件难事反复回来，用写日记应对焦虑与压力讲了“消化”和“反刍”之间的界线。

常见问题

一个每日日记模板该有几个栏目？

四到六个。每个栏目都是每晚要交的一小笔税，而有十个栏目的模板往往一个月之内就被放弃了。至少留一个开放栏目，装那些你没打算写的东西——真正有用的内容，通常就来自那里。

每天都用同一个模板吗？

基本上是——模板的意义就在于让你不必再做决定。保留一套日常版式，再加一个忙碌时期用的一行流水账备用方案，以及一个难熬日子专用的模板。每月检查一次栏目，删掉那些你总是跳过的。

模板会不会让写日记变得很机械？

如果每个栏目都是封闭的，确实可能。解法就是最后那个开放栏目：结构帮你起步，之后你跟着冒出来的东西走。如果还是像在填表，就把其中两个栏目换成一条每周更换的提示。

每周复盘值得多花那点时间吗？

它是本页价值最高的一项。每日的记录是在记；每周复盘才是你把它们读回去、看见任何单篇日记都不包含的规律的时刻。如果你只来得及做一件事，就做复盘，允许自己漏掉几篇日常记录。

这些模板能用在纸上吗？

可以——这里每一种版式都是按手抄可行的标准写的。用纸的话，睡前先把标题写到下一页上，这样你坐下来时页面已经准备好了。纸唯一做不到的，是替你重新抄一遍模板，以及让你日后能搜索这些栏目。
