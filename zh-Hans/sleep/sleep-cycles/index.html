睡眠周期与睡眠阶段详解

最近更新：2026年8月

睡眠并不是持续八小时的同一件事。它是四种状态不断重复的序列 — 三个非REM阶段加上REM — 你的大脑大约每90分钟循环一次，一夜四到六次。每个阶段承担不同的任务，而它们的比例从第一个周期到最后一个周期会发生巨大变化。

这也解释了为什么6:30醒来可能比6:00醒来更难受、为什么生动的梦大多出现在后半夜，以及为什么在夜末少睡一小时和在夜初少睡一小时完全不是一回事。

四个睡眠阶段

研究人员通过脑电波、眼球运动和肌肉张力来判读整夜睡眠；下面的时长取自成年人夜间中段的一个周期。

阶段每个周期的典型时长占整夜比例作用
N1 — 浅层过渡期1–7分钟约5%入睡的门槛：肌肉放松，你可能会抽动或有坠落感。很容易被叫醒，事后往往还不承认自己睡着了。
N2 — 浅睡眠10–25分钟，越到后面越长约45–55%心率和体温下降。出现睡眠纺锤波和K复合波 — 与记忆巩固以及在噪音中维持睡眠有关的脑电爆发。
N3 — 深睡眠／慢波睡眠前半夜20–40分钟，后半夜接近于零约15–25%身体修复的关键阶段：生长激素分泌、组织修复、免疫功能，以及清除大脑中的代谢废物。最难被叫醒。
REM — 快速眼动睡眠前半夜10分钟，后半夜可长达一小时约20–25%生动做梦、情绪加工，以及程序性记忆和情绪记忆的巩固。大脑高度活跃，身体则暂时处于麻痹状态。

一个周期的顺序是N1 → N2 → N3 → 回到N2 → REM，然后重复。两个周期之间短暂醒来是正常的 — 大多数成年人一夜会醒好几次，却一次也记不住。

90分钟周期，以及它如何变化

90分钟是平均值：实际周期大约在70到120分钟之间，并且因人而异、同一夜中也会变化；第一个周期通常最短。变化最大的是构成：前三分之一夜以深睡眠为主 — N3主导第一和第二个周期，REM大约只有十分钟。到第四或第五个周期时，N3往往已经消失，REM则延长到45–60分钟，这就是你在醒来前梦得最生动的原因。

晚睡两小时却按时起床，损失的主要是深睡眠；提早两小时醒来，损失的主要是REM — 两种不同的损失，这也是短睡之夜会让你既身体乏力又情绪脆弱的原因之一。如果你更关心深睡眠，请参见如何获得更多深度睡眠。

为什么在周期中途醒来那么难受

睡眠惯性 — 醒来后那种沉重的迷糊感 — 在闹钟把你从N3中拽出来时最严重。它可能持续半小时，反应速度和判断力确实会受损 — 有时比整夜没睡还糟。在浅层N2或REM刚结束时醒来则温和得多 — 这就是按90分钟的倍数安排就寝时间的道理，而我们的睡眠计算器会替你算好。

但请把它当作经验法则：周期并非精确的90分钟，你也不会在关灯的瞬间就睡着，而一个被打断的夜晚会把这套算术全部打乱。总睡眠时长胜过精巧的时机计算 — 整整齐齐四个周期的六小时，比在周期中途结束的七个半小时更糟。用它在两个现实可行的就寝时间之间做选择，绝不要把它当作熬夜的理由。

哪些因素会打乱你的睡眠结构

在床上躺满八小时，睡眠阶段的构成仍然可能很差。常见的元凶包括：

  • 酒精 — 把深睡眠提前集中到前半夜，随后抑制REM并使后半夜支离破碎。睡前一杯酒买来了第一个周期，代价是后面三个。
  • 咖啡因 — 半衰期长达五小时，意味着下午的那杯咖啡到午夜仍在起作用，即使你能顺利入睡，深睡眠也会被削减。
  • 过晚的大餐和傍晚的高强度运动 — 两者都会升高核心体温，而体温下降正是触发深睡眠的条件之一。
  • 作息不规律 — “深睡眠优先”的模式需要你的生物钟与实际就寝时间保持一致。
  • 未经治疗的睡眠呼吸暂停 — 反复的呼吸中断会整夜把你从深睡眠和REM中拽出来：在床上九小时，几乎没有恢复性睡眠。值得了解一下这些信号。
  • 年龄 — 从中年开始，N3会自然减少。

调整日常习惯就能解决这份清单上的大部分问题；睡眠卫生清单说明了哪几项最重要。

常见问题

一个睡眠周期有多长？

平均约90分钟，但实际周期大致在70到120分钟之间，同一个人在同一夜里也会有差异。第一个周期通常最短。请把90分钟当作规划用的估算值，而不是秒表刻度。

我需要几个睡眠周期？

四到六个 — 换句话说就是7–9小时。追求周期数量并不是捷径：五个各75分钟的周期只有6小时15分钟，对大多数成年人来说还不够。各年龄段的范围请参见你需要睡多久。

哪个睡眠阶段最重要？

它们承担不同的任务，所以谁也不比谁更重要。N3深睡眠负责身体修复、免疫功能和大脑废物清除；REM负责情绪加工和记忆。缺少深睡眠，你会觉得身体乏力；缺少REM，你会觉得情绪紧绷。完整的一夜会按合适的比例同时给你两者。

为什么我总是在闹钟响之前就醒了？

通常这是好现象。夜里最后几个周期以REM为主、睡眠较浅，而你的生物钟在你醒来之前就已经开始提升核心体温和皮质醇。如果你稳定地提前几分钟醒来并且感觉良好，一般说明就寝时间和你的睡眠需求匹配得不错。

应用或手表能告诉我睡眠阶段吗？

不能做到准确。可穿戴设备是从运动和心率推测阶段的；总睡眠时长估算得还算可以，但阶段层面的准确度有限，深睡眠最难判断准确。一本记录时间、质量和习惯的睡眠日记，能告诉你更多可以据此采取行动的信息。
